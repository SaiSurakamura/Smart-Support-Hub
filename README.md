# Smart Support Hub

Учебный веб-прототип панели внедрения, эксплуатации и сопровождения программного продукта.

## Стек

- HTML5
- CSS3
- JavaScript
- localStorage
- Chart.js
- GitHub Pages
- Crypto Subtle API (SHA-256, имитация доступа)

## Запуск

1. Установить VS Code.
2. Установить расширение Live Server.
3. Открыть папку проекта.
4. Запустить `index.html` через Live Server.

## Основные модули

- Dashboard
- Deployments
- Incidents
- Maintenance
- Releases
- Настройки (профили, dev-режим, сброс данных)

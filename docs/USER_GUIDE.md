# Руководство пользователя

## Назначение

Smart Support Hub — это панель для команды поддержки программного продукта.  
С её помощью можно вести внедрения, регистрировать инциденты, планировать сопровождение и отслеживать версии продукта.

## Как зарегистрировать инцидент

1. Откройте страницу **Инциденты**.
2. Заполните поле **Описание**.
3. Выберите **Приоритет**.
4. Нажмите **Создать инцидент**.
5. При необходимости нажмите **Решить**, чтобы закрыть инцидент.

## Как создать заявку на изменение

1. Откройте страницу **Заявки**.
2. Укажите название заявки.
3. Выберите вид сопровождения.
4. Выберите статус.
5. Укажите целевую версию.
6. Нажмите **Добавить заявку**.

## Куда обратиться

По вопросам работы системы можно обратиться к администратору панели или создать инцидент в разделе **Инциденты**.
